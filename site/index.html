Catch generic AI output before it ships

Agents reach for the same defaults every time: a tiny label over each heading, a sparkle on every smart button, a hero with three cards, seamless in the first sentence.

antiSlopdev gives {{rules}} of those defaults a name and a stable ID, and checks {{checked}} of them in your UI, copy, docs, commits and code. Open source, MIT.

Install

Agent skill
npx skills add aconymouse/antislopdev
Claude Code
/plugin marketplace add aconymouse/antislopdev
Checker
npx antislopdev check src

    How a finding is judged
    
    
    block is never acceptable in shipped work and fails the run. justify fails unless someone writes the reason next to it, like antislopdev-allow UI-11: the wordmark gradient is the brand. warn is a smell, and three of the same rule in one file count as justify.
    
    
    None of this asks for a particular look. Gradients, dark themes, monospace and motion are fine when someone chose them. The rules only ask that the choice was made.
