# Code of conduct

This project argues about defaults for a living, so disagreement is expected. Keep it about the work.

## Expected

- Critique the rule, the code or the sentence, never the person who wrote it.
- Back a claim with an example. "This flags too much" lands better with the snippet that shows it.
- Be patient with people writing in their second language. Many contributors here are.
- When a maintainer makes a call, you can disagree once, clearly, and then let it rest.

## Not okay

Harassment, insults, slurs or discriminatory jokes, personal attacks, sexual comments or attention, publishing someone's private details, and repeatedly derailing a thread.

## Reporting

Email hi@aconymous.com. Reports are read only by the maintainer and handled in confidence. Depending on what happened, the response ranges from a private word to a removed comment or a ban from the project's spaces.

This applies everywhere the project lives: issues, pull requests, discussions and any channel that speaks for it.
